## ✨ Overview

**GamerFolio** is a gaming identity and library platform. Track what you play, discover your next adventure, show off your gaming journey, and chat directly with other players.

This repo is a **production-minded full-stack template**:

- ⚡ Next.js frontend with real game artwork and responsive layouts
- 🛠️ Express + Prisma API backed by PostgreSQL
- 💬 Socket.IO-ready messaging
- 🧩 Clean service abstractions so demo data can be swapped for a live backend

## ⚡ Quick Start

<details open>
<summary><b>🪟 Windows PowerShell</b></summary>

```powershell

pnpm install

Copy-Item apps\web\.env.example apps\web\.env.local
Copy-Item apps\api\.env.local.example apps\api\.env
```

## 🔐 Environment Variables

> ⚠️ Never commit `.env` or `.env.local`.

<details>
<summary><b>🖥️ Frontend</b> · <code>apps/web/.env.local</code></summary>

```env
NEXT_PUBLIC_API_URL=http://localhost:5000/api
NEXT_PUBLIC_SOCKET_URL=http://localhost:5000
NEXT_PUBLIC_GOOGLE_CLIENT_ID=your-google-client-id.apps.googleusercontent.com
```

</details>

<details>
<summary><b>⚙️ Backend</b> · <code>apps/api/.env</code></summary>

```env
PORT=5000
NODE_ENV=development

DATABASE_URL=postgresql://postgres:postgres@localhost:5432/gamerfolio

FRONTEND_URL=http://localhost:3000

GOOGLE_CLIENT_ID=your-google-client-id.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=your-google-client-secret

JWT_SECRET=replace-with-a-long-random-secret-at-least-32-characters
JWT_EXPIRES_IN=7d

GAME_API_CLIENT_ID=
GAME_API_CLIENT_SECRET=
```

Generate a secure JWT secret:

```bash
node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
```

</details>

**Required for production:** `DATABASE_URL` · `FRONTEND_URL` · `GOOGLE_CLIENT_ID` · `GOOGLE_CLIENT_SECRET` · `JWT_SECRET`

> 💡 IGDB / Twitch credentials are optional. The frontend ships with fallback game data for local development.

## 🔌 API Integration

The frontend talks to the backend through service abstractions, keeping the UI independent from the API implementation.

| Service | Responsibility |
| :--- | :--- |
| 🔐 `authService` | Google sign-in, sessions, sign-out |
| 🎮 `gameService` | Game listing and search |
| 📚 `libraryService` | User-game CRUD |
| 👥 `userService` | User search and profiles |
| 💬 `chatService` | Conversations and messages |
| 🌐 `apiClient` | Shared HTTP client and API envelope handling |

## 🌍 Deployment

### ▲ Frontend on Vercel

Set the project root to `apps/web` and add:

```env
NEXT_PUBLIC_API_URL=https://your-api-domain.example/api
NEXT_PUBLIC_SOCKET_URL=https://your-api-domain.example
NEXT_PUBLIC_GOOGLE_CLIENT_ID=your-production-google-client-id
```

Vercel detects the Next.js app automatically.

### 🚂 Backend on Render, Railway, or any Node host

Set the service root to `apps/api`.

```bash
# Build
pnpm install --frozen-lockfile
pnpm --filter @gamerfolio/api build

# Run migrations
pnpm --filter @gamerfolio/api prisma:migrate:deploy

# Start
pnpm --filter @gamerfolio/api start
```

Configure:

```env
DATABASE_URL=your-hosted-postgresql-url
FRONTEND_URL=https://your-frontend-domain.example
GOOGLE_CLIENT_ID=your-production-google-client-id
GOOGLE_CLIENT_SECRET=your-production-google-client-secret
JWT_SECRET=your-production-jwt-secret
```
